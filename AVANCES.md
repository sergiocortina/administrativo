## LECCIONES APRENDIDAS

### 1. Formato de cada unidad

```
### Unidad X
**Nombre:** ...
**Fechas:** ...
**Objetivo de aprendizaje:** ...
**Saberes:** (numerados X.1, X.2...)
**Actitudes y valores:** (3 actitudes, 3 valores, personalizados por contenido)
**Evidencias de aprendizaje:** (tabla: evidencia / instrumento / %)
**Metodología:** (5 pasos numerados + párrafo final)
```

### 2. Reglas clave

- **Saberes**: extraer de los headings de la exposición teórica del libro-curso. Entre 6 y 10 por unidad.
- **Actitudes/valores**: NO copiar institucionales genéricos. Redactar específicos al contenido de cada unidad usando formato: ADJETIVO (actitud) o SUSTANTIVO (valor) + descripción.
- **Evidencias**: 3 por unidad. Usar instrumentos del Catálogo UCC (Examen con clave, Lista de cotejo, Rúbrica para valorar exposiciones, Rúbrica para valorar casos prácticos, Rúbrica para valorar proyectos de investigación).
- **Metodología**: 5 pasos (1: lectura previa, 2: exposición profesor, 3-4: actividades, 5: cierre). Alternar individual/equipo.

### 3. Herramientas útiles

- `pdftotext` (MiKTeX) para extraer texto de PDFs
- Extraer DOCX como ZIP + XML para leer Word sin Microsoft Office
- Catálogo de Evidencias UCC 2023 como referencia de instrumentos

## LECCIONES APRENDIDAS (15 ago 2026)

1. **Reveal.js 5.1.0 navega por hash usando el atributo `id` de la sección, NO `data-id`.** El código usa `document.getElementById()` / `getAttribute("id")`. `data-id` solo sirve para auto-animate. Los enlaces `href="#/mi-seccion"` requieren `id="mi-seccion"` en el `<section>`. (Verificado leyendo `dist/reveal.js` del CDN.)
2. **Botón de índice: usar la API de Reveal** (`Reveal.getIndices(el)` + `Reveal.slide(h, v, f)`) en vez de `location.hash = '#/indice'`: al navegar a una diapositiva sin id, Reveal *debouncea* 1s la limpieza del hash y reasignar el mismo hash no dispara `hashchange`.
3. **Contador de fragmentos**: `slide.querySelectorAll('.fragment')` (total) y `slide.querySelectorAll('.fragment.visible')` (mostrados). Escuchar `slidechanged` + `fragmentshown` + `fragmenthidden`. Ocultar con clase (no `display` inline) y resetear texto a `0/0` cuando no hay fragmentos.
4. **Tests con Chrome headless vía CDP** funcionan en Windows: lanzar `chrome --headless=new --remote-debugging-port=PORT --user-data-dir=<tmp>`, crear tabs con `PUT /json/new?url=...`, evaluar JS con `Runtime.evaluate`. El endpoint `/json/new` ya NO acepta GET (solo PUT).
5. **Ojo con codificación en consola de Windows**: `PYTHONIOENCODING=utf-8` para emojis en Python; el `dump-dom` de Chrome para tests simples.
6. **Caché de GitHub Pages**: después del push, el sitio puede verse viejo por caché del navegador → recarga forzada (`Ctrl+Shift+R`) o ventana de incógnito. El servidor suele estar al día en segundos.
